Esta política explica quais dados o app OYWA e o site www.oywa.it tratam, e como.

Esta é uma tradução do original em italiano. Em caso de divergência, prevalece a versão em italiano.

1.Controlador e contato

Controlador dos dados: Giuliano Razzicchia. Para qualquer dúvida sobre privacidade: staff@oywa.it.

Esta política se refere ao app OYWA, um app para arquivar os lugares visitados nas viagens, e ao site www.oywa.it.

2.Princípio básico: os dados do app ficam no seu dispositivo

Os dados que você insere no app (lugares, visitas, viagens, cidades, pessoas, avaliações, notas e tudo o que você salva) ficam guardados exclusivamente no banco de dados local do seu celular. O OYWA não tem servidores próprios que recebam ou guardem os seus dados, e não exige conta nem login.

3.Dados que o app envia a serviços de terceiros

Para algumas funções o app se conecta a serviços externos. Isso só acontece quando você usa a função correspondente:

  • Mapa (OpenStreetMap). As imagens do mapa são baixadas dos servidores do OpenStreetMap (tile.openstreetmap.org). O servidor recebe o endereço IP do dispositivo e a área do mapa que você está vendo.
  • Busca e geocodificação (Nominatim, OpenStreetMap). Quando você busca um lugar, o texto da busca é enviado para nominatim.openstreetmap.org. Quando o app descobre a cidade e o país a partir de uma localização (por exemplo ao adicionar um lugar ou importar um arquivo), as coordenadas são enviadas ao mesmo serviço.
  • Apps de navegação. Quando você escolhe abrir um lugar no Mapas, Google Maps ou Waze, o app passa as coordenadas para esse app. A partir daí vale a política de privacidade dele.

O OYWA não usa ferramentas de análise, publicidade, relatórios de falhas ou rastreamento de terceiros.

4.Localização

O app pode pedir acesso à localização do dispositivo, só enquanto você o usa, para preencher automaticamente a cidade e o país quando você adiciona um novo lugar. A localização não é salva nem enviada ao OYWA. As coordenadas são usadas para a solicitação de geocodificação descrita no item 3. Você pode negar a permissão a qualquer momento nos ajustes do celular; as outras funções continuam disponíveis.

5.Permissões solicitadas pelo app

  • Localização (durante o uso): opcional, descrita no item 4.
  • Rede (Internet): necessária para o mapa, a busca de lugares e a geocodificação descritas no item 3.
  • Arquivos: o app só lê os arquivos que você escolhe, por exemplo um backup ou um arquivo KML/KMZ para importar, e grava o arquivo de exportação que você depois compartilha.

6.Backup e exportação

Você pode criar um backup completo (arquivo .oywa) ou exportar uma seleção de lugares para KML, Excel ou PDF. O arquivo é criado no dispositivo e compartilhado só por você, pela folha de compartilhamento do sistema (por exemplo iCloud Drive, Google Drive, e-mail ou mensagens). O OYWA não recebe nem guarda esses arquivos. Quem recebe um arquivo exportado o trata segundo as próprias regras.

7.Perda do dispositivo ou desinstalação

Como os dados estão no dispositivo, o OYWA não pode recuperá-los. Se você desinstalar o app sem um backup, os dados serão perdidos. Recomendamos exportar um backup periodicamente e guardá-lo num lugar seguro.

8.Conservação e exclusão

Os dados ficam no dispositivo até você apagá-los ou desinstalar o app. Ao apagar um lugar ou uma viagem, o dado é removido do banco de dados local.

Você pode apagar a qualquer momento todo o seu arquivo (lugares, visitas, viagens, cidades e pessoas) em Definições → Seus dados → Apagar todos os dados. A exclusão é definitiva: se quiser guardar os dados, exporte antes um backup. As preferências do app, como o idioma, ficam no dispositivo até você desinstalar o app.

9.O site www.oywa.it

O site é hospedado no GitHub Pages, um serviço da GitHub, Inc. (Estados Unidos). Quando você visita o site, os servidores do GitHub registram o endereço IP e alguns dados técnicos da solicitação (navegador, página solicitada, data e hora) para prestar o serviço e por motivos de segurança. O controlador não tem acesso a esses registros e não os utiliza. O GitHub aderiu ao EU-U.S. Data Privacy Framework; mais informações estão na declaração de privacidade do GitHub.

O site não usa cookies, ferramentas de análise ou publicidade e não carrega recursos de servidores de terceiros: até as fontes tipográficas ficam hospedadas no próprio site. Os detalhes estão na política de cookies.

10.E-mail e pedidos para a versão de teste

Se você nos escrever em staff@oywa.it, por exemplo para participar da versão de teste, tratamos o seu endereço de e-mail, o seu nome se você informar e o conteúdo da mensagem. Usamos esses dados só para responder e, se você pedir, para avisar quando a versão de teste estiver disponível e enviar as instruções de instalação.

A base legal é o seu pedido (art. 6.º, n.º 1, alínea b, do RGPD) e, para os avisos sobre a versão de teste, o seu consentimento (alínea a), que você pode retirar a qualquer momento. O e-mail é gerenciado pelo provedor Register S.p.A. (Itália). Guardamos esses dados pelo tempo necessário para atender ao pedido e, para quem participa dos testes, até o fim da fase de testes. Não os repassamos a terceiros e não os usamos para marketing.

11.Menores

O OYWA é destinado a pessoas com pelo menos 16 anos. O app não pergunta a idade e não coleta dados dos usuários: o que você insere fica no seu dispositivo e o OYWA não recebe.

12.Seus direitos

Nos termos do Regulamento (UE) 2016/679 (RGPD) você tem direito de acesso, retificação, apagamento, limitação, portabilidade e oposição. Como os dados do app estão no seu dispositivo, você pode exercer a maioria desses direitos diretamente no app, inclusive exportando ou com “Apagar todos os dados”. Para os dados de e-mail, escreva para staff@oywa.it. Para pedidos relativos aos dados tratados pelos serviços de terceiros indicados nos itens 3 e 9, fale diretamente com esses serviços. Você também tem o direito de apresentar reclamação à autoridade italiana de proteção de dados (garanteprivacy.it) ou à autoridade do seu país.

13.Alterações

Se esta política mudar, atualizaremos a data no topo e, quando for relevante, avisaremos você no app.
